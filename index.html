Primeiros passos no HTML e CSS

Publicado pela Turma do 1º D

Nas primeiras semanas de aula, aprendemos a dar estrutura para os nossos sites usando tags HTML e a deixar tudo visualmente atraente com regras de CSS. Descobrimos como criar cabeçalhos, parágrafos, listas e adicionar cores aos projetos!

Adicionando Interatividade com JavaScript

Publicado pela Turma do 1º D

Depois de dominar a estrutura e o estilo, começamos a explorar o JavaScript. Agora, nossas páginas podem responder a cliques de botões, criar alertas e dinamizar elementos na tela em tempo real.

Projetos Finais: Nossos Próprios Sites

Publicado pela Turma do 1º D

Cada grupo do 1º D está desenvolvendo um projeto autoral para aplicar tudo o que aprendeu. Estamos criando desde portfólios pessoais até blogs de temas variados. A tecnologia agora é nossa aliada!
